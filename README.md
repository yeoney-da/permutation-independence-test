# permutation-independence-test
Independence test for categorical data using permutation methods / Permutation test를 이용한 범주형 자료의 독립성 검정

**범주형 자료의 독립성을 검정하기 위해 Permutation Test를 적용하고, Pearson 카이제곱 검정 결과와 비교한 통계분석 프로젝트입니다.**

## 1. 프로젝트 개요

- **주제:** MBTI 유형(E/I)과 혈액형 간의 독립성 검정
- **분석 대상:** 설문조사를 통해 수집한 혈액형 및 MBTI 정보
- **분석 목적:** 두 범주형 변수 사이의 독립성을 검정하고, 카이제곱 검정의 적용 조건이 충분하지 않은 경우 Permutation Test를 활용할 수 있는지 살펴봅니다.
- **분석 도구:** Python

## 2. 분석 배경 및 문제 정의

혈액형과 MBTI의 E/I 성향 사이에 통계적으로 유의한 연관성이 존재하는지 확인하고자 하였습니다.

혈액형(A, B, O, AB)과 MBTI(E, I)를 기준으로 4×2 분할표를 구성하고 Pearson 카이제곱 독립성 검정을 수행하였습니다.

그러나 AB형 응답자 수가 9명으로 적었으며, 일부 셀의 기대빈도가 5 미만으로 나타나 카이제곱 검정의 근사적용 조건을 검토할 필요가 있었습니다.

이에 따라 관측된 자료의 분포를 재배열하는 Permutation Test를 적용하여 독립성을 검정하고, 기존 카이제곱 검정 결과와 비교하였습니다.

## 3. 분석 방법

### ① 탐색적 데이터 분석
- 혈액형 및 MBTI(E/I) 응답 분포 확인
- 두 변수의 교차표 작성
- 셀별 기대빈도 계산 및 카이제곱 검정 적용 조건 검토

### ② Pearson 카이제곱 독립성 검정
- Pearson 카이제곱 통계량 계산
- 자유도 3인 카이제곱 분포를 이용한 검정 결과 확인

### ③ Permutation Test
- 관측된 데이터에서 한 변수의 범주를 무작위로 재배열
- 각 반복에서 Pearson 카이제곱 통계량 계산
- 반복적으로 생성한 통계량의 분포와 관측 통계량 비교
- Permutation 분포를 기반으로 p-value 산출

### ④ 결과 비교
- Pearson 카이제곱 검정과 Permutation Test 결과 비교
- 카이제곱 분포를 이용한 근사 검정과 순열분포를 이용한 검정의 차이 확인

## 4. 주요 분석 결과

| 분석 항목 | 결과 |
|---|---|
| 교차표 크기 | 4×2 |
| AB형 응답자 수 | 9명 |
| AB형 & E 성향 기대빈도 | 4.24 |
| Pearson 카이제곱 통계량 | 1.5367 |

- 일부 셀의 기대빈도가 5 미만으로 나타나 카이제곱 검정의 적용 조건을 검토하였습니다.
- Permutation Test를 통해 표본의 재배열에 기반한 검정통계량의 분포를 구성하였습니다.
- 두 검정 방법의 결과를 비교하여 검정 방법에 따른 차이를 살펴보았습니다.

## 5. 프로젝트를 통해 다룬 내용

- 범주형 자료의 교차분석 및 독립성 검정
- Pearson 카이제곱 검정의 가정과 적용 조건
- Permutation Test를 이용한 비모수적 통계적 추론
- 반복적인 무작위 표본 재배열을 통한 검정통계량의 경험적 분포 생성
- 이론적 카이제곱 분포와 순열분포의 비교
